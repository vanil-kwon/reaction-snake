# Changelog

All notable changes to Reaction Snake are documented here.

## [1.0.0] - 2026-11-25

First public release.

- Five playable modes: Classic, Reflex, Survival, Precision and Daily.
- Reflex mode affects the Snake gameplay, measures response time, rewards faster evasive turns and records a personal best.
- 16 cosmetic skins, 40 achievements and local coin progression.
- English, Russian and German interface.
- Responsive touch and keyboard controls.
- Sound effects, procedural music, dark/light themes and reduced visual effects.
- Installable web app manifest and service-worker offline cache.
- Local-only saves and settings; no account, game server, purchases, ads or game analytics.
- Improved Reflex record persistence and safer offline navigation fallback.

## Release notes

- First visit requires an internet connection so the app files can be cached.
- After a successful first load, the game is designed to work offline from the same browser/device.
- Progress is not synchronized between devices. Clearing browser/site data can erase local progress.
- Browser/device compatibility still needs hands-on testing across the target devices; CI checks syntax and release invariants but do not replace real-device gameplay testing.
- The repository does not currently specify a software license.
